## Welcome to Quan's Github

My name is **Quan Tran**, currently a final-year B.Sc. student in **Mechatronic Systems Engineering** at Rhein-Waal University of Applied Sciences in **Kleve, Germany**.

I completed an **internship in ESS Modeling & Simulation** at PowerCo SE (Volkswagen Group), gaining hands-on experience in **battery systems**, **BMS fundamentals**, and **energy storage modeling** using `MATLAB/ Simulink/Simscape`.

At university, I designed and built a **Wireless emergency stop system** for an **Electric Go-Kart** using `ESP32/ESP8266`, strengthening expertise in wireless communication, real-time control, and system reliability. Skilled in circuit design, PCB layout (EAGLE), and hardware prototyping, with extensive laboratory work including soldering, assembly, and testing. Proficient in `C/C++` (Arduino IDE) for embedded programming and integration of WiFi and LoRa modules to achieve stable wireless communication in safety-critical applications.

Interested in batteries, energy storage systems, robotics, and intelligent mechatronic systems.
